Getting started

There are three ways to write Eaze. Pick whichever fits your machine — the language is identical everywhere.

1. The Playground (easiest)

Download Eaze Playground v1.0.0 for Windows, either the guided installer or the portable build that runs from anywhere. Open it, type a program, press Run (or F5).

2. From source

Requires Node.js 18+:

# Clone the engine, install, open the REPL
git clone https://github.com/MR-STARK87/Eaze.git
npm install
npm start

3. Your first program

One statement per line. Store values with set … to, print them with show:

set name to "Ada"
show "Hello, " + name
show "Welcome to Eaze."
Output→ Hello, Ada
→ Welcome to Eaze.

Language tour

Eaze reads like structured English. There are no semicolons, no braces, and no cryptic symbols: blocks open with a plain word (if, repeat, while, define) and always close with end.

WordDoesExample
set … toCreates or updates a variableset score to 10
show / sayPrints a value (aliases)show score
ask … intoAsks the user, stores the answerask "Age?" into age
if / else / endRuns code only when trueif score > 5
repeat … timesLoops a fixed number of timesrepeat 3 times
whileLoops while a condition holdswhile score < 100
define / call / returnReusable functionsset x to call add(2, 3)
and / or / notPlain-word logicif a and not b
One rule to remember: every block opener needs its end. Indentation is for humans — Eaze follows the ends.

Variables

Variables are created the moment you assign them. Names use letters, numbers, and underscores, and must start with a letter or underscore.

set age to 25
set price to 99.99
set name to "Ada"
set total to price + age

# Reassign freely — variables are mutable
set age to 26
show age
Output→ 26

Data types

Three kinds of values cover nearly every beginner program: numbers, strings, and lists.

Numbers

Integers and decimals, including negatives. Arithmetic is + - * /; dividing by zero is an error.

set whole to 42
set pi to 3.14
set debt to -100
show 2 + 3 * 4   # 14 — × before +
Output→ 14

Strings

Single or double quotes both work. Join strings with +.

set first to "Ada"
set last to 'Lovelace'
show first + " " + last
Output→ Ada Lovelace

Truthiness

Conditions treat 0 and "" as false; everything else counts as true — the same intuition as everyday language.

Output

show prints any value; say is a friendly alias that does exactly the same thing. Each statement prints one line.

say "Counting down:"
show 3
show 2 + 1
show [1, 2, 3]
Output→ Counting down:
→ 3
→ 3
→ [1, 2, 3]

Input

ask shows a prompt and stores the answer with into. If the answer looks like a number, Eaze converts it automatically — so age + 1 just works.

ask "What is your name?" into name
ask "How old are you?" into age
show "Next year you turn "
show age + 1
Output (typed: Ada, 30)→ Next year you turn
→ 31

Precedence

Eaze evaluates in this order (lowest first): or → and → comparisons → + - → * / → not and unary - → calls and indexing → values in parentheses. Parentheses always win:

show 2 + 3 * 4     # 14
show (2 + 3) * 4   # 20
Output→ 14
→ 20

Conditionals

if runs a block only when its condition holds; else covers everything else. Chain them for multi-way decisions.

ask "Score?" into score

if score >= 80
  show "Great job!"
else
  if score >= 50
    show "You passed."
  else
    show "Keep practicing."
  end
end
Output (typed: 92)→ Great job!

Loops

Two loops cover every beginner need. repeat counts iterations for you; while keeps going until a condition breaks.

# A fixed number of times
repeat 3 times
  show "Hello"
end

# Until a condition changes
set n to 3
while n > 0
  show n
  set n to n - 1
end
show "Blast off!"
Output→ Hello
→ Hello
→ Hello
→ 3
→ 2
→ 1
→ Blast off!
Watch out: a while loop whose condition never becomes false runs forever. Always change something inside the body — like n above.

Lists

Lists hold ordered collections. Counting starts at 0, items can mix types, and you can rewrite any slot with set … to.

set fruits to ["Apple", "Banana", "Cherry"]
show fruits[0]

set fruits[1] to "Blueberry"
show fruits

# Walk a list with a counter
set i to 0
while i < 3
  show fruits[i]
  set i to i + 1
end
Output→ Apple
→ [Apple, Blueberry, Cherry]
→ Apple
→ Blueberry
→ Cherry
Read the output carefully: the second line is the whole updated list; the last three lines are the loop printing each fruit. Tracing output line-by-line is a core debugging skill.

Functions

Package logic into reusable blocks with define, run them with call, and hand values back with return. Functions remember the variables around them (closures) and can call themselves (recursion).

define square(n)
  return n * n
end

ask "Number to square?" into n
set result to call square(n)
show result
Output (typed: 7)→ 49
# Recursion: a function that calls itself
define factorial(n)
  if n <= 1
    return 1
  else
    return n * call factorial(n - 1)
  end
end

show call factorial(5)
Output→ 120
Arity matters: calling a function with the wrong number of arguments is a runtime error — define add(a, b) must be called as call add(5, 3). If a function ends without return, it quietly hands back nothing.

CLI & REPL

The command line ships with the engine. Open an interactive session with npm start (or node cli/index.js), or run a file directly:

# Interactive mode
npm start

# Run a saved program
node cli/index.js examples/fibonacci.eaze

The REPL detects unfinished blocks and keeps prompting until you close them with end. These commands work at any prompt:

CommandDoes
helpCommand list, language recap, operator reference
varsInspect every variable and function currently defined
clearClear the screen and redraw the banner
exitLeave the REPL
EazeA hidden message about the language. Try it.

Playground

The desktop Playground (Windows installer or portable build) wraps the same engine in a visual workspace:

  • Editor + console — write on the left, see output instantly on the right. F5 runs, Ctrl+Shift+F tidies indentation, Ctrl+S saves.
  • Blocks bar — one-click snippets for every keyword, so beginners never face a blank page.
  • Files sidebar — open folders of .eaze files, create, rename, and organize programs; the desktop build works with real files on disk.
  • Themes & fullscreen — light and dark boards that match the site, plus F11 focus mode for classrooms.
  • Templates & help — fourteen starter programs (greeter, countdown, guessing game, password lock…) and a built-in reference, no internet required.

Everything runs locally — your programs never leave your machine except when you explicitly ask the AI assistant for help.

AI assistant

Three helpers live in the Playground's AI panel, there to teach rather than to do the work for you:

  • The Explainer — reads your code and its structure, then describes the logic in plain English.
  • The Debugger — when an error strikes, explains why it happened and suggests a surgical fix.
  • The Transpiler — converts Eaze into clean, idiomatic JavaScript, bridging the path to professional languages.
# Eaze in…
repeat 3 times
  show "Hello"
end
// …and what the Transpiler makes of it
for (let i = 0; i < 3; i++) {
  console.log("Hello");
}

Example programs

Complete, runnable programs from the examples/ folder. Copy any of them into the Playground or a .eaze file.

Fibonacci sequence

# Prints the first N Fibonacci numbers
ask "How many Fibonacci numbers?" into n
set a to 0
set b to 1

show "Fibonacci Sequence:"

repeat n times
  show a
  set temp to a + b
  set a to b
  set b to temp
end

show "Done!"
Output (typed: 5)→ Fibonacci Sequence:
→ 0
→ 1
→ 1
→ 2
→ 3
→ Done!

Guessing game

show "I am thinking of a number from 1 to 10."
set secret to 7
set guess to -1

while guess != secret
  ask "Your guess?" into guess

  if guess < secret
    show "Too small!"
  else
    if guess > secret
      show "Too big!"
    else
      show "Correct!"
    end
  end
end

Mini calculator

ask "Number A?" into a
ask "Number B?" into b

show "A + B ="
show a + b

show "A - B ="
show a - b

if b == 0
  show "A / B = (cannot divide by 0)"
else
  show "A / B ="
  show a / b
end

Troubleshooting

Eaze errors always name the line and column. The five messages below cover nearly every beginner stuck-point:

You seeIt meansFix
I don't know what 'x' isUsing a variable before creating itAdd set x to … first
Expected endA block was never closedMatch every if / repeat / while / define with end
expects 2 arguments but got 1Wrong argument count in a callCount the parameters in define
Unexpected characterA symbol Eaze doesn't use (e.g. ; { $)Delete it — one statement per line needs no punctuation
Division by zeroExactly what it saysGuard with if b == 0 first

Still stuck? Paste the error into the Playground's Debugger — explaining why is literally its job.

Roadmap

Shipped in v1.0: the Windows Playground (installer + portable), the CLI/REPL, fourteen starter templates, and the AI learning assistant.

Next, the language: richer lists, a Math + String standard library, and local file I/O for bigger programs. Next, the reach: native macOS and Linux builds.

Deliberately not on the list: classes, modules, and type annotations. Eaze stays small on purpose — it is a first step into programming, and a confident one.
